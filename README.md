# Barracuda discovery
Barracuda discovery patterns for ServiceNow. The XML files are update sets.

## Files
Barracuda CloudGen Firewall.xml => Discovery pattern for Barracuda CloudGen Firewalls

Barracuda Control Center.xml => Discovery pattern for Barracuda Control Center

Barracuda Control Center schedule.xml => Discovery Schedule, Serverless Execution Pattern and Connection &amp; Credential Alias for Barracuda Control Center

Barracuda Firewall SNMP.xml => SNMP Classifier, OID and probe to launch discovery of Barracuda Firewalls

Pre-sensor script instructions.md => How to create a Pre/Post Script to handle model and manufacturer
